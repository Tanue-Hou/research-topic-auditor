# Multi-Agent Workflow — 多智能体协作工作流

## 概述

定义选题审查任务的多智能体协作模式，各 Agent 分工明确，主 Agent 负责协调和综合。

## 角色定义

### 1. Searcher — 文献检索 Agent

| 属性 | 说明 |
|------|------|
| 职责 | 多平台论文检索、去重、结构化输出 |
| 加载 Skill | academic-search |
| 输入 | 关键词、学科、时间范围、数量 |
| 输出 | 结构化论文清单（统一 metadata schema） |
| 成功标准 | 达到用户要求的论文数量且字段完整 |

### 2. Frontier Analyst — 前沿分析 Agent

| 属性 | 说明 |
|------|------|
| 职责 | 趋势分析、Citation Burst 检测、关键词变迁 |
| 加载 Skill | research-topic-auditor + academic-search |
| 输入 | 论文清单 |
| 输出 | 趋势报告 JSON |
| 成功标准 | 完成所有关键指标计算 |

### 3. Gap Analyst — 空白识别 Agent

| 属性 | 说明 |
|------|------|
| 职责 | 方法-任务矩阵构建、空白检测、Future Work 挖掘 |
| 加载 Skill | research-topic-auditor + academic-search |
| 输入 | 论文清单 |
| 输出 | 空白区报告 JSON |
| 成功标准 | 至少识别 3 个空白区并评分 |

### 4. Novelty Judge — 创新性评估 Agent

| 属性 | 说明 |
|------|------|
| 职责 | 多维度创新性评分、差异化分析 |
| 加载 Skill | research-topic-auditor |
| 输入 | 论文清单 + 用户提案 |
| 输出 | 创新性评估报告 |
| 成功标准 | 完成所有维度评分并有可解释的依据 |

### 5. Synthesizer — 综合 Agent

| 属性 | 说明 |
|------|------|
| 职责 | 综合所有子报告，生成选题建议 |
| 加载 Skill | research-topic-auditor |
| 输入 | 所有子 Agent 输出 |
| 输出 | 选题建议报告（Markdown）|
| 成功标准 | 输出完整的、结构化的、可直接使用的报告 |

## 子 Agent Prompt 模板

```
你必须严格加载并遵循 [academic-search / research-topic-auditor] Skill 的指令。

目标：[具体任务描述]

学科：[CS/医学/物理/化学/社科/人文]

输入数据：[传递结构化输入或引用]

输出格式：[指定格式]

成功标准：
1. [标准 1]
2. [标准 2]

注意：
- 不要生成无引用支撑的结论
- 数据来源必须标注平台
- 无法获取时如实报告，不要编造
```

## 失败处理

| 失败情况 | 处理方式 |
|---------|---------|
| Agent 返回空结果 | 调整 query 重新分发（最多 2 次）|
| Agent 超时 | 主 Agent 记录"部分失败"，用已有信息继续 |
| 引用数获取失败 | 标记为 "citation: unknown"，不影响其他字段 |
| 趋势数据不足 | 标注 "insufficient data"，缩小时间窗口或放宽 scope |
