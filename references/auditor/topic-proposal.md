## 概述

## 排序算法

```
综合评分 = 0.35 × gap_score + 0.25 × novelty_score + 0.20 × feasibility_score + 0.10 × impact_score + 0.10 × alignment_score
```

| 综合评分 | 推荐程度 |
|:--------:|:--------:|
| ≥ 4.0 | 强烈推荐 |
| 3.5 - 3.9 | 推荐 |
| 3.0 - 3.4 | 可选 |
| < 3.0 | 不推荐 |
